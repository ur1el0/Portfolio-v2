### System Overview
Architected a centralized scholarship platform featuring eligibility filtering, application tracking, and automated announcements for local government units and student applicants.

### Technical Implementation
* **REST API Services:** Built ASP.NET Core REST APIs and React interfaces backed by PostgreSQL database containerization.
* **Database & Workflows:** Streamlined eligibility criteria evaluation, student document submissions, and provider administration workflows.
